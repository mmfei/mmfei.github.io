CSS微动效

默认不播放。播放中可暂停，并可改时长和缓动。缓动名用的是 CSS 关键字，不是某套产品的私有曲线。下面三个同页标签按 WAI-ARIA tabs 的手动激活：左右方向键只移动焦点，Enter 或空格才显示面板。上下方向键不拦截。

<div class="dot"></div>
<style>
.dot {
  width: 40px;
  height: 40px;
  background: #3d3a9a;
  animation: slide 240ms ease-out infinite alternate;
}
@keyframes slide {
  from { transform: translateX(0); }
  to { transform: translateX(96px); }
}
@media (prefers-reduced-motion: reduce) {
  .dot { animation: none; transform: none; }
}
</style>

  • 何时使用：短反馈，例如进入或按下。时长用毫秒。
  • 常见错误：进页就自动循环；系统已要求减少动态仍继续位移；复制出来的代码和正在播放的参数不一致。
  • 左右方向键只在这组标签里移动焦点。上下方向键仍留给页面滚动。这不是底部导航。

说明与来源

原则来自下面三份公开文档，示例和代码是本页自己的。没有测量任何竞品界面。Motion 仓库的 README 写核心库是 MIT，并把 Motion+ 示例和额外 API 标成付费；本页没有安装或引用 motion，这一小段位移只用 CSS animation。弹簧和拖拽不在这批。

  • WAI-ARIA 模态对话框：打开后焦点进入对话框，Tab 不跑出去，Escape 关闭。
  • WCAG 2.2 理解文档 2.3.3：交互触发的动画应能关掉，除非它是理解信息所必需的。
  • MDN easing-function 与 prefers-reduced-motion：缓动是 CSS 关键字；系统开启减少动态时去掉非必要位移动画。

导航、卡片栅格、轻提示、抽屉、页面转场和配色不在这页。按钮、表单、弹窗和列表只在这页操作，不提供各自的完整代码。已上线的 字体对比 在工具总览里。
