免费资源

17 条 · 最近核实 2026-11-26

本页只做介绍，入口跳转到对方官方页面。我们不托管、不镜像、也不代为领取。额度、限制和活动随时可能变化，一切以对方当前页面为准。

本页只介绍免费域名、服务器、GPU 与设计稿并链到官方页面，开源软件精选在 资源导航。

EU.org 免费子域名

域名

用途

为个人或非营利组织提供免费子域名（如 example.eu.org）。官方称与欧盟无关。

怎么领取

打开 nic.eu.org 注册或登录后申请。直接挂在 eu.org 下的名字一般只提供 NS 委派，需自备或另找 DNS 托管。

限制

额度
官方写免费提供子域名注册，未写数量上限。直接在 eu.org 下自动注册的名字须至少 4 个字符。
时长
未写固定到期日；服务长期存在，但不等于永久保证。
绑卡
官方政策页未要求信用卡。
地区
非欧洲站点也欢迎。主要面向个人和非营利；小型商业站点官方「非常强烈建议」仅在没有其他选择时再注册。

风险提示

无强制绑卡或自动扣费说明。部分国家子域（页面列出的 CY/GR/NL.eu.org）不在此站办理。

最近核实：2026-11-26

官方入口 https://nic.eu.org/

is-a.dev 免费子域名

域名

用途

给个人开发者作品集、以及与软件开发相关的非商业项目提供 *.is-a.dev 子域名。

怎么领取

用个人 GitHub 账号，按 文档 在 is-a-dev/register 提交 Pull Request，审核合并后生效。

限制

额度
免费。子域不得买卖、出租或变现。官方 TOS 写服务按现状提供，不保证可用性或永久性。
时长
未写固定年限；运营方可随时终止。
绑卡
官方 TOS/文档未要求信用卡。
地区
未写地区限制；TOS 受澳大利亚法律管辖。须年满 13 岁；只能挂到个人 GitHub 账号，不能用 Organization 账号。

风险提示

禁止商业、营利或政治用途。

最近核实：2026-11-26

官方入口 https://docs.is-a.dev/

JS.ORG 免费子域名

域名

用途

为与 JavaScript 生态直接相关的站点提供免费 *.js.org 子域名（常见做法是给 GitHub Pages 做短地址）。

怎么领取

先准备好有实质内容的站点，添加 CNAME 或配置自定义域，再向 js-org/js.org 提交 PR。官网写通常 24 小时内生效。

限制

额度
免费。条款写用户不对子域享有所有权，服务可终止或修改。
时长
未写固定年限；若终止某个或全部子域，至少提前 7 天通知。
绑卡
官方条款未要求信用卡。
地区
未写地区限制；条款适用德国法。

风险提示

网站必须与 JavaScript 生态直接相关。「仅仅使用了 JavaScript 的个人页或作品集」不够格。

最近核实：2026-11-26

官方入口 https://js.org/

GitHub 学生开发包（域名权益）

域名

用途

通过 GitHub 教育认证后，在合作方处领取限时免费域名。本轮在官方 Pack 页读到：Namecheap 提供 1 年 .me；Name.com 提供部分后缀（页面举例 .live、.studio、.software、.app、.dev）；.TECH 提供 1 年标准 .TECH 域名。

怎么领取

先按 GitHub Education 完成学生认证，再在 Pack 页进入对应合作方领取。第三方产品条款由合作方约束。

限制

额度
各合作方各有一条「一年免费」或「选定后缀免费」说明；官方写优惠不可多次兑换，也不能靠重新认证来重置限时优惠。
时长
学生认证有效期 2 年，之后需重新验证；域名免费期以合作方写的「1 年」为准。
绑卡
GitHub Pack 页未写清各注册商是否要绑卡，本轮也未核到合作方官方说明。
地区
须通过 GitHub 学生认证，且年满 13 岁。教师等教育用户官方写明无资格领取 Pack。合作方是否限制国家，本轮未在合作方页核实。

风险提示

一年后是否自动续费、是否绑卡，本轮未核到，以合作方领取页为准。第三方优惠可能被合作方随时变更。

最近核实：2026-11-26

官方入口 https://education.github.com/pack/

阿里云 ECS 免费试用

服务器

用途

给完成实名认证的 ECS 新用户，在额度内试用云服务器。

怎么领取

完成实名后前往 免费试用中心，按 ECS 试用攻略 从控制台「我的试用进度」创建实例。未付费购买或试用过 ECS，账号无欠费。同一用户仅 1 次。

限制

额度
个人实名总免费额度 300 元，每小时上限 0.833 元；企业实名 660 元，每小时上限 1.833 元。文档举例：若每小时 0.833 元，300 元大约只够连续用约 15 天。
时长
免费试用有效期 3 个月；实际可跑时长取决于额度消耗速度。
绑卡
试用攻略强调实名认证，未写必须绑定信用卡。账户欠费则不能申请。
地区
文档列出 7 个免费地域，包括北京、杭州、广州、成都、乌兰察布、河源、中国香港。创建后不能直接换地域。当前试用是按量模式，暂不满足国内站 ICP 备案要求。

风险提示

免费试用到期后，实例不会自动释放，会按照按量付费模式计费。务必及时释放，避免继续产生费用。

官方入口 https://help.aliyun.com/zh/ecs/user-guide/ecs-free-trial

服务器

用途

官方 FAQ 写接受信用卡，以及功能类似信用卡的借记卡；不接受带 PIN 的借记卡，以及虚拟卡、一次性卡、预付卡。
地区
在提供商业 OCI 的区域可用；300 美元赠金「available in select countries」。

风险提示

AWS Free Tier

服务器

用途

新客户可在免费计划下用额度试用部分 AWS 服务；另有 30 多种服务在月度限额内 Always Free。这已不是旧版「开户起 12 个月免费套餐」对所有新账户的默认结构。

怎么领取

在 AWS Free Tier 创建新账户。已有或曾有 AWS 账户则无资格领取这套免费计划和额度。

限制

额度
新客户最多合计 200 美元额度（注册即得 100 美元，完成控制台活动最多再得 100 美元）。
时长
Free plan 自开户起 6 个月，或额度用尽，以先到者为准。到期后账户会暂停，数据保留 90 天，须在此期间升级，否则永久关闭并删除内容。条款和 FAQ 对额度过期时间有 6 个月与 12 个月的不同表述，以条款或控制台显示为准。
绑卡
官方 FAQ 写多数新客户注册不必提供支付方式；有时可能为验证身份而要求提供。
地区
额度可用于全球参与区域。官方明确：中国宁夏（ZHY）、北京（BJS）区域不适用此套 Free Tier credits 与账户计划，需看中国区自己的页面。

风险提示

AWS 全球免费额度不适用于中国宁夏/北京区域。Free plan 到期是关停而不是自动扣费；升级到付费计划后，超出部分按标准价计费。

最近核实：2026-11-26

官方入口 https://aws.amazon.com/free/
